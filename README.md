# React Practice

Small React and TypeScript exercises for learning hooks and component fundamentals.

## Repository structure

```text
useState/
  demo.tsx
useEffect/
  dummy.tsx
package.json
package-lock.json
```

## Install dependencies

From the repository root, install the project dependencies with:

```bash
npm install
```

The `node_modules/` directory is excluded from Git. The exercise components are examples to import into a React app; this repository does not currently include an app entry point or a start script.
